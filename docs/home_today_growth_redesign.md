# 首页「今日推荐 + 成长区」视觉改版 — 最终设计稿

> 版本：2026-09-04 · 状态：**定稿（待开发）**  
> 范围：Web PWA + Android Flutter 首页中段  
> 原则：静穆纸感 · 零 guilt · 一屏一事 · 读经第一

---

## 1. 设计目标

| 目标 | 做法 |
|------|------|
| 今日推荐更轻、更可扫 | 2×2 独立卡片，**无外层灰底壳** |
| 每格有专属视觉 | **上图下文** + 坑位固定插图 / 书封 |
| 成长区不像系统列表 | 3 张 **全宽横卡**，与 2×2 **构图错开** |
| 整体不单调 | Hero 大横图 → 2×2 方格 → 全宽长卡，三种节奏 |

## 3. 今日推荐 · 2×2 卡片

### 3.1 布局

| 属性 | 值 |
|------|-----|
| 容器 | `display: grid; grid-template-columns: 1fr 1fr; gap: 8px` |
| 单卡总高 | **116px**（Web）；Android 对齐 **116 logical px** |
| 图区高 | **64px**（固定，非比例，便于双端一致） |
| 文区高 | **52px**（含内边距） |
| 圆角 | **14px**（整卡） |
| 图区圆角 | 仅顶部：`14px 14px 0 0` |
| 边框 | `1px solid color-mix(in srgb, var(--ink) 8%, transparent)` |
| 阴影 | `var(--home-shadow)` |
| 背景 | 文区 `var(--surface)`；图区由图片/插图铺满 |

### 3.2 单卡结构（上图下文）

```
┌─────────────────────┐
│                     │  64px  专属图 / 书封 / 运营 cover
│      object-fit     │        object-fit: cover; object-position: center
│        cover        │
├─────────────────────┤
│ [标签]              │  10px · uppercase 或正常 · muted · 单行截断
│ 标题                │  13px · font-weight 600 · 最多 1 行
│ 副文 / 进度         │  11px · muted · 最多 1 行（可选）
│ ▓▓▓░░░░  进度条      │  仅 plan/resume 且有 progressPct 时 · 高 2px
└─────────────────────┘
```

**不要：**
- 卡片内绿色 CTA pill（「进入」「继续」等按钮样式）
- 图区全幅白字 overlay（与 Hero 抢戏）
- 外层再包一层 `.home-today-shell`

**可点区域：** 整卡 `button`，`:active` → `opacity: 0.94; scale(0.99)`

### 3.3 坑位与排序（定稿 · 固定四格）

**2×2 阅读顺序（从左到右、从上到下）：**

```
┌─────────────┬─────────────┐
│ [1] 活动     │ [2] 继续阅读 │
│  或 书架     │             │
├─────────────┼─────────────┤
│ [3] 共读     │ [4] 祷告     │
└─────────────┴─────────────┘
```

| 位置 | 固定内容 | 数据来源 | tag |
|------|----------|----------|-----|
| **[1]** | **活动**；无活动时 **书架** | `campaigns[0]` → 否则 `shelf` | 活动 tag / **书架** |
| **[2]** | **继续阅读** | `resume` → 否则 `suggest` 自由读 | **继续阅读** |
| **[3]** | **共读** | `group` | **共读** |
| **[4]** | **祷告** | `prayer` | **祷告** |

**关键规则：**

- 活动**只占 [1]**，不再挤占共读 / 祷告坑
- 无活动（`campaigns` 为空）时，[1] **永远出书架**，不出现空白
- [2] **仅圣经续读**；读经计划留在**成长区**，不进四坑
- 四坑**始终满格**（2×2），不做 3 张 span-2 变体（除非未来产品另议）

**[1] 书架回退逻辑：**

| 条件 | 标题 | 副文 | 跳转 |
|------|------|------|------|
| 有最近书柜阅读 `bookId` | 书名 | 可选副标题 | `/shelf/{id}/read` 或详情 |
| 无最近阅读 | 打开书柜 | 灵修书与资料 | `/shelf` |

专属图：`tile_shelf.jpg`（无活动且无书封时）

**张数布局：**

| 张数 | 布局 |
|------|------|
| 4 | 标准 2×2（默认，固定） |

### 3.4 状态

| 状态 | 视觉 |
|------|------|
| 默认 | 标准边框 + 阴影 |
| `pending`（共读待打卡） | 边框 `var(--accent-deep)` + 极轻外 glow；可选 `groupFlash` 一次脉冲 |
| `done` | 整卡 `opacity: 0.58`；角标「已完成」10px |
| `badge`（如 2/5） | 图区右上小圆角 chip，白底 80% |

### 3.5 标签 copy

| 位置 | tag |
|------|-----|
| [1] 活动 | 运营 tag 或「活动」 |
| [1] 书架 | **书架** |
| [2] | **继续阅读**（欢迎回来时可为「欢迎回来」） |
| [3] | **共读** |
| [4] | **祷告** |

## 4. 坑位固定摄影（Unsplash）

### 4.1 规范

- **比例：** 800×400 crop（2:1），图区 `object-fit: cover`
- **风格：** 低饱和、柔光、静穆；与 Hero 风景同气质
- **许可：** [Unsplash License](https://unsplash.com/license)，详见 `illustrations/home/index.json`
- **优先：** 运营 cover → 书卷封面 → 下表固定摄影

### 4.2 资产清单

路径：`apps/web/public/illustrations/home/`

| 文件 | 坑位 | 画面 | 摄影师 |
|------|------|------|--------|
| `tile_activity.jpg` | [1] 活动 | 微开门与透入的光 | Prashant |
| `tile_shelf.jpg` | [1] 书架回退 | 木质书架阅读空间 | Unsplash |
| `tile_read.jpg` | [2] 继续阅读 | 柔光下打开的书 | Liana S |
| `tile_fellowship.jpg` | [3] 共读 | 户外共读 / 查经 | kimber |
| `tile_prayer.jpg` | [4] 祷告 | 白色蜡烛柔光 | Gazi Tasnuva |

### 4.3 代码映射

```ts
// apps/web/lib/home_today_tile_image.ts — 固定 .jpg 路径
```

**设计意图：**
- **阅读** = 书封摄影（真实去向）+ `tile_read.jpg` 兜底
- **关系灵修** = 固定摄影（长期可识别）
- **活动** = 运营图优先，无图用 `tile_activity.jpg`
- 同坑位插图**不随日轮换**，仅书封 / 运营图变

### 4.4 缩略预览（开发自检）

本地预览：`/illustrations/home/tile_*.jpg`  
图区 64px 高时，主要识别元素居中，避免细线贴边。

## 5. 成长区 · 3 张全宽横卡

### 5.1 原则

- **保持 3 张全宽**，不做 2×2
- **构图与今日推荐错开：** 左图右文（现有 `HomeMediaRow` 方向）
- **卡片语言统一：** 圆角 14px、同边框、同 `--home-shadow`
- **去掉「设置列表感」：** 右 chevron 改为 `opacity: 0.28` 或移除

### 5.2 三张卡规格

| 顺序 | 类型 | 高度 | 左图 | 右侧信息 |
|------|------|------|------|----------|
| 1 | 摘要 `summary` | **88px** | 52×52 thumb + 可选环图 progress | **大数字** metric + detail |
| 2 | 功能 `plan` 等 | **76px** | 52×52 固定 tone 图 | eyebrow(tag) + title + detail |
| 3 | 功能 | **76px** | 同上 | 同上 |

间距：`gap: 8px`（与 2×2 一致）

### 5.3 左图来源（沿用 + 微调）

| tone | 图 | 说明 |
|------|-----|------|
| summary | `homeMediaSceneUrl('summary')` 或时钟 icon | 可换 `tile_read` 裁剪 |
| plan | `homeMediaSceneUrl('plan')` | 固定风景 day=8 |
| theme | `homeMediaSceneUrl('theme')` | 固定 day=21 |
| prayer | `homeMediaSceneUrl('prayer')` | 固定 day=14 |
| memory | 书封或 memory 风景 | 按 href 解析 |

**可选增强（非必须 v1）：** 左缘 3px 色条 — plan `#8a9c7c`、theme `#8b93a3`、prayer `#8aa3a8`

### 5.4 摘要卡特殊处理

- 数字（如 `12`）用 `.home-media-metric-value`，**28–32px**
- 摘要卡阴影可略强：`box-shadow: 0 2px 8px color-mix(in srgb, var(--ink) 6%, transparent)`
- 与下方功能卡 **无分割线**，仅靠高度差建立层级

### 5.5 与今日推荐去重

逻辑不变：`home_growth_cards.ts` 的 `occupiedFromTodayPanel` 避免同计划/同群重复出现。

## 6. 节奏与防单调

| 手段 | 说明 |
|------|------|
| **形态三角** | Hero 竖向大图 → 2×2 密方格 → 全宽横条 |
| **图种混搭** | 书封摄影 + 5 张坑位摄影 + 偶发运营图 |
| **字号阶梯** | Hero 最大 → 摘要数字 → 2×2 标题 → detail 最小 |
| **单一动效焦点** | 仅 `pending` 共读或继续阅读进度条吸引注意 |
| **节令克制** | 季节运营只占活动坑或 Hero，不整页换色 |
