# 本章朗读 — 产品规格（定稿）

> 版本：**v1.3**  
> 更新日期：**2026-09-02**  
> 适用范围：圣经 Tab · 阅读页  
> 双端：**PWA（iOS 主路径）** + **Android Flutter 原生壳**  
> 关联：`docs/PRODUCT.md` §5.2 · `docs/READING-EXPERIENCE.md`

---

## 0. 产品句与边界

**产品句：** 在读经页里，让耳朵跟上眼睛——不是独立的「听经 App」。

| 做 | 不做 |
|----|------|
| 圣经 Tab · 当前章朗读 | 首页 hero、发现、IM 推音频 |
| 默认边听边读 + 精简迷你条 | 独立听经 Tab、歌单、排行榜 |
| 可选专注朗读（上滑全屏） | 选中经节条入口、章列表标记 |
| 后台/锁屏继续播（可设置） | 内嵌音量条、均衡器、睡眠故事 |
| 音频始终免费 + 版权致谢 | 听经时长计入 streak / guilt 文案 |

**与 PRODUCT 关系：** 废止「绝对不做听读」；能力收束在 **圣经 Tab 辅助朗读**，不在首页主推。

## 1. 设计原则

| 原则 | 落地 |
|------|------|
| 经文第一 | 默认不离开阅读页；控件退后 |
| 静穆纸感 | 纸卡片迷你条，无专辑封面、无大绿播放钮 |
| 一屏一事 | 默认 Layer 0+1；全屏需主动上滑 |
| 零 guilt | 不统计「今日听了几章」；阅读报告不计听经分钟 |
| 层次靠排版 | 顶栏「声纹 + 朗读」文字主语义；现代分段器/settings |
| 双端事对齐 | 同一 API、状态语义、文案；UI 允许微差 |

## 2. 唯一入口 · 顶栏「声纹 · 朗读」

全 App **仅 1 处入口**，无目录「继续朗读」、无章列表角标、无选中条扩展。

```
┌──────────────────────────────────────────────────┐
│ 约翰福音 3 │ 新译本▼    概要    🔍   ▮▮▮ 朗读   ⋮ │
└──────────────────────────────────────────────────┘
                                      ↑
                                 唯一入口
```

### 2.1 组合钮规格

| 属性 | 值 |
|------|-----|
| 类名 | `reader-audio-btn`（与 `reader-summary-btn` 同族） |
| 热区 | 高 40pt，左右 padding 8pt，宽约 56–60pt |
| 结构 | 左 **12×12 声纹 SVG** + 右 **「朗读」13px medium** |
| 位置 | 搜索 🔍 与 ⋮ 之间 |

### 2.2 声纹 SVG（12×12）

三竖条底对齐，隐喻「声音」；与 🔍 同 stroke 体系（`strokeWidth="1.6"`，`round cap`）。

```svg
<line x1="2"  y1="10" x2="2"  y2="6"  />
<line x1="6"  y1="10" x2="6"  y2="3"  />
<line x1="10" y1="10" x2="10" y2="5"  />
```

### 2.3 四态

| 状态 | 声纹 | 「朗读」 | 背景 |
|------|------|----------|------|
| idle | 静态，`--ink-faint` | `--ink-faint` | 透明 |
| playing | accent 色 + 错峰伸缩 1.2s | `--accent-deep` | 可选 `--accent-wash` 6% 圆角 8pt |
| paused | 静态 gray | `--ink` | 透明 |
| unavailable | 斜线，`opacity 0.35` | 同 | Toast「此译本暂无朗读」 |

- 顶栏 **始终保持「朗读」文案**，不切换为 ▶/‖（语义稳定）
- 点按：播放/暂停；长按：朗读设置 Sheet
- `prefers-reduced-motion`：playing 仅改文字色，声纹不动

### 2.4 无障碍

```
aria-label="本章朗读，未播放|播放中|已暂停|此译本不可用"
aria-pressed="true|false"  // playing 时 true
```

### 2.5 首次引导

| 项 | 规格 |
|----|------|
| 文案 | 「可以听本章」 |
| 触发 | **仅当当前章有音频** 且 `reader_audio_coach_seen=0` |
| 形态 | 按钮下 8pt 尖角气泡，2.5s 淡出，永久一次 |

### 2.6 窄屏降级（`<360px` 且溢出）

仅显示 12px 声纹，隐藏「朗读」二字；`aria-label` 保持完整。

## 3. 音频与屏幕译本解耦（P0）

朗读绑定 **音频源译本**（默认 `cuvs`），与屏幕主译本可不一致。

| 场景 | 行为 |
|------|------|
| 屏幕 CNV + 音频 cuvs | 迷你条副信息：`约翰福音 3 · 和合本朗读` |
| 屏幕译本无声源 | 按钮 unavailable；Toast「此译本暂无朗读 · 可切换和合本收听」 |
| 切换屏幕译本 | 若新译本无声源 → 停止播放 + 灰态；**不自动改** 用户阅读译本 |

## 4. 三层 UI + 底栏 Tab 布局

### 4.1 Layer 定义

| Layer | 名称 | 说明 |
|-------|------|------|
| **0** | 阅读正文 | 节级高亮（有 timestamps 时） |
| **1** | 精简迷你条 | 播放时出现 |
| **2** | 专注朗读 | 用户上滑进入 |
| **3** | 朗读设置 Sheet | 半屏 |

### 4.2 Z 轴与锚点

```
z=0   阅读正文
z=5   五 Tab 底栏
z=15  小爱 FAB + 打卡 FAB
z=20  迷你朗读条
z=10  Sheet / 半屏小爱
```

| 场景 | 迷你条 `bottom` | 正文 `padding-bottom` | FAB |
|------|-----------------|----------------------|-----|
| Tab 显示 | `calc(var(--tabbar-h) + 8px)` | +52px | 上移 64px |
| 沉浸藏 Tab | `calc(var(--safe-bottom) + 12px)` | +52px | 贴底公式上移 |
| 专注全屏 | — | 默认 | 隐藏 |
| Sheet 打开 | 隐藏 | 默认 | 隐藏 |

章末 `scroll-padding-bottom` ≥ 迷你条 + Tab + 24px。

### 4.3 沉浸态规则（P1）

| 模式 | Tab | 迷你条 |
|------|-----|--------|
| 默认播放 | 显示 | Tab 上方 |
| 用户点按沉浸 | 隐藏 | **随 Tab 藏** → 贴 `safe-bottom` |
| 专注全屏 | 隐藏 | 合入 Layer 2 |

## 5. Layer 1 · 精简迷你条（定稿）

**原则：** 迷你条只做 **播停 · 进度 · 展开**；切章、倍速、定时进专注层或设置 Sheet。

### 5.1 线框

```text
┌────────────────────────────────────────────┐
│ ━━━━━━━━━━━━━●━━━━━━━━━━━━  1:02 / 4:05    │  ← 3px 轨，顶边全宽
│  [ ‖ ]   约翰福音 3 · 和合本朗读        [^] │  ← 高 48pt 纸卡片
└────────────────────────────────────────────┘
   32pt        13px 单行 ellipsis           上滑
```

**仅 3 个交互元素：** 播停钮 · 标题行 · 展开钮。无「下一章」、无 ⋮、无 ±15s。

### 5.2 视觉

| 属性 | 值 |
|------|-----|
| 高 | 48pt（含 3px 进度轨） |
| 圆角 | 16pt |
| 背景 | 纸色 95% + `blur(12px)` + 1px `--line` |
| 播停 | 32pt 圆角方，内矢量 ‖/▶，stroke 2px 圆头 |
| 展开 | chevron up 单线，24pt 热区 |
| 时间 | tabular 12px tertiary，右对齐于进度轨 |

### 5.3 交互

| 操作 | 结果 |
|------|------|
| 点 ‖/▶ | 暂停/继续 |
| 点 [^] / 上滑条 | 进入 Layer 2 |
| 下滑条 >72px | 停止并收起 |
| 拖进度轨 | 章内 seek |
| 长按条或顶栏钮 | 朗读设置 Sheet |

### 5.4 与其他 UI 共存

| 场景 | 迷你条 |
|------|--------|
| 经节选中 | 收成 **4pt accent 进度线** |
| 半屏小爱 | **隐藏**（音频继续） |
| 目录 / 计划 overlay | **隐藏** + **暂停**音频 |
| Sheet 打开 | 隐藏 |

## 6. Layer 0 · 边听边读

### 6.1 节级高亮（M2 · 有 timestamps）

```css
.verse-audio-current {
  background: color-mix(in srgb, var(--accent-deep) 8%, transparent);
  border-radius: 4px;
}
```

- 与用户笔记黄 `#FFF3B0` **区分**
- 对照模式：仅高亮主译本行

### 6.2 章级（M1 · 无 timestamps）

- 不高亮节；章首 2px accent 左边线 + 12px「正在朗读本章」

### 6.3 滚动

- 当前节进入视区中 1/3 → gentle scroll 300ms
- 用户手动滚后 **8s 内**不抢滚动权

## 9. 换章 / 导航 / 译本（P0）

| 操作 | 行为 |
|------|------|
| 播放中左/右滑换章 | 文本 + 音频切新章；若设置「换章后继续」ON → **自动播新章**（默认 ON） |
| 未播放时换章 | 无音频行为 |
| 顶栏换章 popover | 同左滑 |
| 搜索 / 计划 / 深链跳入 | **不自动播** |
| 点「朗读」 | 播当前章 |
| 切换屏幕译本（无声源） | 停止 + 灰态 |

首次「播放中换章」Toast 一次：「已随章节切换朗读」（`reader_audio_chapter_toast_seen`）。

## 10. 后台与锁屏播放

### 10.1 设置项

| 项 | 默认 | 说明 |
|----|:----:|------|
| 锁屏或切换应用后继续 | ON | 主开关 |
| 离开圣经 Tab 时暂停 | OFF | 开则切 Tab 即停 |
| 播放中滑动换章后继续 | ON | 见 §9 |

持久化：`reader_audio_*`（localStorage / SharedPreferences）。

### 10.2 PWA

- `<audio>` + **Media Session API**（metadata + play/pause/prev/next chapter）
- 能力因 iOS 版本而异；设置内诚实脚注

### 10.3 Android

- `just_audio` + **`audio_service`** 前台通知
- 通知：**无封面图**；卷章名 + 细线播停 + 文字「上一章/下一章」

### 10.4 中断与音频焦点（P1）

| 事件 | 行为 |
|------|------|
| 来电 / 导航语音 | 暂停；结束后 **不自动续** |
| 蓝牙断开 | 暂停 + 弱 Toast |
| 耳机拔出（Android） | 暂停 |

## 11. 网络 / 加载 / 单例（P0）

| 状态 | UI |
|------|-----|
| 首次拉流 | 迷你条 + 进度轨 **indeterminate shimmer** |
| 失败 | Toast「朗读加载失败」+ 条内「重试」文字链 |
| 弱网 | 服务端流式 + 预加载下一章；失败可重试 |
| 离线 | Toast「需要网络加载本章朗读」；**不提供音频文件下载** |

- 全 App **单例** `<audio>`：跳章先停旧会话
- 服务端：BB 失败 → FHL 镜像；客户端只见 `/bible/audio/stream/...`

| 状态 | 顶栏 | Tab | FAB | 迷你条 |

| playing + mini | ✓ | ✓ | 上移 | ✓ |

## 16. P2 · 后续增强（写入路线图）

| 项 | 说明 | 阶段 |
|----|------|------|
| **预加载下一章** | 播到 70% 静默 prefetch 下一章 MP3 | ✅ M3 |
| **同章断点续播** | 24h 内记住 seek；换章清零；**不**在目录提示 | ✅ M3 |
| **连续朗读** | 本章结束后自动下一章；设置默认关 | ✅ M3 |
| **离线章包** | ~~Android 设置「下载和合本朗读」~~ **不做**：朗读仅在线流式，与经文离线包分离 |
| **kjv 音频** | 屏幕 kjv → `unavailable`（「此译本暂无朗读」）；暂无 FHL 英音源，未来可接 Bible Brain |
| **轻 haptic** | Android 播/停 10ms | ✅ M3 |
| **倍速记忆** | 本地持久化上次倍速 | ✅ M1 |
| **Android 省电** | 进程被杀后不自动续；用户再点「朗读」 | ✅ M3 |
| **Flutter WebView** | 白名单 H5 页不启动 Media Session，防双实例 | M1 |

**P2 刻意不做：** 内嵌音量、播放列表 UI、听经徽章、与小爱 TTS 合并、LLM 朗读。
