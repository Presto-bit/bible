## 0. 一句话

圣经阅读页、小爱上方点「听」→ **展开全屏听读面**；MiniMax `speech-2.8-turbo` 朗读**当前屏幕主译本**正文。下滑只关界面、音频继续；默认**沉稳男声**；章末默认续听下一章；永不读节号。**仅按需合成** + 全局缓存；时间轴 **按节合成再拼接**。沉浸时听钮与小爱一并全隐（**无幽灵态**）。PWA 与 Android **同发**；旧章 MP3 **下线**。

## 1. 对照微信读书（摘要）

入口在阅读器内；全屏听读；跟读；可拖进度；续听默认开。不抄会员墙、排行、真人有声商城、独立听书馆。

**读：** 章引子一次、正文、小标题、诗歌正文。  
**不读：** 节号、脚注、交叉引用、对照副栏、笔记/UI。

---

## 2. 目标与非目标

**目标：** 读经场景延展；听读一体；按需+缓存控成本；静穆零 guilt。  
**非目标：** 听经 Tab/歌单/克隆声/听经打卡/顶栏旧入口/迷你条双层/FHL MP3/幽灵悬浮停钮。

## 3. 体验规格

### 3.1 入口：小爱 FAB 上方 · 点听 = 展开全屏

```
        ┌────┐
        │ 听 │  ← 点按：打开/展开全屏听读面
        └────┘
        ┌────┐
        │ 小爱│
        └────┘
```

| 规则 | 说明 |
|------|------|
| 位置 | 小爱正上方，间距同现网 FAB 叠 |
| **点「听」** | **打开/展开全屏**：idle 开面并开始准备/播放；已在播或已暂停且面已关 → **只展开面，不切换播停**；面已开则听钮随叠隐藏 |
| 播停 | **只在全屏中心键**（及系统播控）；**不要**用点听来暂停 |
| **沉浸** | chrome 隐藏时：**听 + 小爱一并完全隐藏**（与未播时相同）；**不保留幽灵听钮** |
| 选区 / 小爱 Sheet | 整叠可隐，同现网 |
| 长按 | **P0 取消长按菜单** |

#### 听钮外观（chrome 可见时）

| 状态 | 外观 |
|------|------|
| idle | 纸感次级 |
| preparing | 以面内中心键为准 |
| playing | accent + 轻声纹 |
| paused | accent 弱 |
| unavailable | 降透明（无本地主译本章文本等极少情况） |

### 3.1.1 关全屏不暂停

| | 全屏 UI | 音频 |
|--|---------|------|
| 下滑关面 | 关闭 | **继续** |
| 点听（面已关 · chrome 可见） | **展开** | 不变 |
| 面内中心键 | 可开着 | 播 ↔ 停 |

### 3.1.2 沉浸全隐 × 关面不停 × 如何暂停（已拍板：无幽灵）

| 场景 | 行为 |
|------|------|
| chrome 隐藏 | **听、小爱均不可见**（纯读经） |
| playing · 面已关 · chrome 隐藏 | 音频可继续；用户 **点屏唤出 chrome** → 再点听展开全屏 → 中心键暂停；或用 **系统播控**（Android MediaSession；iOS PWA 尽力而为） |
| playing · 面已关 · chrome 可见 | 点听 = 展开全屏（再在面内暂停） |

> 接受代价：沉浸读经时多一步才能停。换来视线干净。首次听读可用一句轻提示：「下滑可继续听；暂停请打开听读页」。

### 3.2 全屏播放面

设置全显；无「第 n/N 节」；纸感氛围背景；书卷行显示 **当前主译本名**。

```
┌─────────────────────────────────┐
│ ░░░░░ 氛围背景 ░░░░░            │
│  ━  下滑只关面                  │
│     约翰福音 3 · {主译本名}      │
│                                 │
│    （当前节正文）                │
│                                 │
│  ────────●──────────            │
│         3:24 / 8:10             │
│      ‹‹      [ ‖ 或 ▶ ]   ››    │
│   语速     音色     定时         │
└─────────────────────────────────┘
```

#### 3.2.0 中心键单态

| 状态 | 显示 | 点按 |
|------|------|------|
| playing | ‖ | 暂停 |
| paused / 可播 | ▶ | 播放/继续 |
| preparing | 加载环 + `正在准备` | 不可切播停；可下滑关面 |

#### 3.2.1 首次按需等待

1. 点听 → **立刻开面**（本地主译本章文本铺底）。  
2. 中心键 **正在准备**。  
3. 命中缓存则速播；未命中则等按节合成拼接。  
4. 准备中可下滑：未出声可取消 job；已出声则关面不停。  
5. 失败：回 ▶ +「准备失败，点按重试」。

#### 3.2.2 视觉

纸感柔光；禁专辑封面/紫渐变/波形卡拉 OK/节序数字。

#### 3.2.3 P1

左右滑切节；近章末提示；点经文区播停；听时减亮。

### 3.3 进度条

可拖；节吸附（依赖按节 timeline）。**无轴则禁用拖动**。

### 3.4 续听

默认开；≥70% 预取下一章（同主译本）；卷末停。下一章 preparing 时面内提示。

### 3.5 粒度

节寻址；按节合成拼接；永不送节号进 TTS。

### 3.6 音色

P0 仅 **沉稳男声**。语速仅播放器变速，不进 TTS/hash。P1 再开另外取向；换音色尽量续进度。

### 3.7 屏幕译本 ≡ 听读译本（已拍板）

| 规则 | 说明 |
|------|------|
| 对齐 | **听读译本 = 阅读页主译本**（CNV / cuvs / 其它已上线主译本均可） |
| 对照 | 副栏 **不读、不进全屏** |
| 首发 | **不限制必须 cuvs**；用户听什么主译本，就合成什么 |
| 听中切主译本 | **暂停并结束当前会话**（或提示将按新译本重新准备）；避免耳眼两套经文 |
| 听中仅换章/书 | 同译本下按新章 preparing |

## 4. 朗读文本管道

```
当前主译本章
  → 过滤对照/脚注/UI → 去节号 → 规范化（P0 单测）
  → 按节列表 → 按节 T2A → 拼接 mp3 + timeline
  → 缓存 listen/{translation}/minimax/speech-2.8-turbo/{voice}/{hash}
```

---

## 5. 技术 · MiniMax

| 项 | 决定 |
|----|------|
| 模型 | `speech-2.8-turbo` |
| 策略 | 仅按需；续听预取下一章；无热章预热 |
| **时间轴** | **按节合成再拼接**（方案 A，已拍板） |
| Key | 仅服务端 |
| 防刷 | 设备/IP/日配额 |
| 旧 MP3 | 下线 |
| 双端 | 同发；iOS 后台诚实说明 |

并行按节请求（限流）→ 拼接；无 timeline 不开拖动。P1 可优化「先播前 N 节再补齐」。

成本：按量约 ¥4/万汉字；按译本分别缓存，多译本会增加冷启动次数（可接受）。

P0 清理旧 `kReaderAudioEnabled` / 顶栏 MP3 / AudioOrb 链路。

## 6. API 草图

```
GET /v1/listen/chapter?translation={primary}&book=&chapter=&voice=voice_calm_m
→ 200 { status: ready, url, timeline, duration_ms, text_hash, next? }
→ 202 { status: pending, job_id }
```

`timeline[]`: `{ verse, start_ms, end_ms }`

## 8. 风险（摘）

| 风险 | 对策 |
|------|------|
| 沉浸时难暂停 | 点屏出 chrome → 听 → 面内 ‖；系统播控；首次轻提示 |
| 多译本缓存变多 | 按需即可；防刷 |
| 冷首次慢 | preparing + 并行按节 |
| 切译本听串 | §3.7 切主译本即停会话 |

---

## 9. P0 成功标准

1. 点听展开全屏；关面后再点听再展开。  
2. 冷首次先开面 +「正在准备」；可下滑。  
3. 沉浸时听钮完全隐藏（无幽灵）；chrome 可见时可再进面暂停。  
4. 听读文本 = 当前主译本；对照栏不读。  
5. 按节 timeline 拖节准；二次同章同译本 0 TTS。  
6. 旧 MP3 不可达。
